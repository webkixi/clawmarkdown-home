使用流程

四步完成一篇高质量图文

从看到好内容到产出自己的图文，整个流程行云流水。

01

采集网页内容

在任意网页点击插件图标，选择「记录此文」，自动提取正文、图片及其上下文，存入本地待处理列表。

02

设置生成参数

在编辑器中选择目标平台风格、目标字数与改写深度，插件会自动校准合理字数范围。

03

龙虾生成图文

调用 claw-markdown-gen 技能，龙虾完成关键字生成、图片规划、图文撰写与去 AI 味润色。

04

编辑与导出

预览渲染效果，局部修改或全文重写，最终复制富文本到公众号、或复制 Markdown 到任意平台。

改写深度

三档深度，适配不同创作场景

从轻量润色到完全原创，按需选择改写强度。

轻度 保留 70% 原文

逐句润色，优化语法与格式

  • 保留原段落顺序与章节结构
  • 逐句保留原意，仅做语法润色
  • 全部保留原文细节、数据、案例
  • 仅使用原文图片占位符
  • 适合：整理素材、快速发布
推荐
中度 相似度 30% 以下

重组结构，用自己的语言重新表述

  • 可调整段落顺序，合并或拆分
  • 按核心价值点重组，提炼 3-5 个主题
  • 论点保留，论据可替换为新案例
  • 添加少量个人见解与使用建议
  • 适合：二次创作、差异化输出
重度 完全重写

打破结构，深度改写并支持 AI 配图

  • 完全重新划分段落与叙事框架
  • 仅保留核心事实，叙述全部重写
  • 大量添加深度分析与行业洞察
  • 支持 SVG / Mermaid / AI 配图
  • 适合：原创内容、深度长文

安装指南

三步上手 ClawMarkDown

几分钟即可完成全部配置，开始你的高效图文创作。

1

安装 Chrome 插件

前往 Chrome 应用商店搜索「ClawMarkDown」，点击「添加至 Chrome」即可完成安装。安装后浏览器右上角会出现插件图标。

前往应用商店
2

安装并配置龙虾服务

下载安装 QClaw 桌面端并启动，在聊天界面发送「我需要 chrome 插件和你连接，请提供连接用网关信息及令牌信息」，记录返回的 Gateway URL 与 Token。

3

在插件中连接龙虾

点击插件图标进入设置页，选择龙虾类型，填写 Gateway URL 与 Token，点击「测试连接」确认成功后保存。技能会自动安装。

可选：多模态 API

如需使用「重度改写」模式的 AI 配图功能，可在设置页配置多模态 API（API Key + API URL）。支持火山引擎方舟、SiliconFlow 等兼容 OpenAI 图片生成接口的服务。未配置时不影响正文生成。

环境依赖 pip install requests 技能运行需要 Python 3 与 curl
常见问题

你可能想知道的

请依次检查：QClaw 服务是否已启动；Gateway URL 的端口号是否与 QClaw 返回的一致；Token 是否过期；防火墙是否阻止了本地连接。本地龙虾默认连接 127.0.0.1，确保端口未被占用。

在龙虾的聊天界面发送「请安装 claw-markdown-gen 技能」，等待安装完成后再试。技能依赖 Python 3 与 curl，并需通过 pip install requests 安装 Python 依赖。

重度改写的 AI 配图需要你在设置页面配置「多模态 API」，提供图片生成服务的 API Key 和 URL。未配置时会自动跳过 AI 配图，保留原文图片占位符，不影响正文生成。

本地龙虾（QClaw / OpenClaw / Hermes）数据不出本机，隐私安全，但需要本地资源运行服务；云端龙虾（ArkClaw）基于火山引擎方舟平台，无需本地部署，开箱即用。两者在功能上一致，可根据你的硬件条件与隐私偏好选择。
